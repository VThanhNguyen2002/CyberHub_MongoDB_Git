# 🛍️ Web Bán Đồ Công Nghệ

## 📖 Giới thiệu

Đây là một ứng dụng web bán đồ công nghệ được xây dựng với mục tiêu cung cấp trải nghiệm người dùng tốt nhất khi mua sắm các sản phẩm công nghệ. Ứng dụng sử dụng **React.js** cho frontend, **Node.js (Express)** cho backend, và **MongoDB Atlas** làm cơ sở dữ liệu. Toàn bộ ứng dụng được triển khai trên **Vercel**.

---

## 🚀 Tính năng chính

### 🎨 Frontend (React.js):
- **Trang chủ:** Hiển thị danh mục sản phẩm.
- **Giao diện hiện đại:** Thiết kế responsive, thân thiện trên mọi thiết bị.

### 🔧 Backend (Node.js):
- **API RESTful:** Cung cấp dữ liệu sản phẩm và người dùng.
- **Xử lý CRUD:** Quản lý sản phẩm
- **Xác thực:** Bảo mật thông qua **JWT**.

### 💾 Cơ sở dữ liệu:
- **MongoDB Atlas:** Lưu trữ dữ liệu sản phẩm, người dùng

### 🌐 Triển khai:
- **Vercel:** Triển khai đồng thời cả frontend và backend.

---

## 🛠️ Công nghệ sử dụng

- **Frontend:** React.js, TypeScript, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Triển khai:** Vercel

---

### 1️⃣ Yêu cầu hệ thống
- **Node.js** >= 14.x
- **npm** hoặc **yarn**
- **Tài khoản MongoDB Atlas**

# 🛍️ Tech Products Web Store

## 📖 Introduction

This is a web application designed for selling tech products, aimed at providing the best user experience for online shopping. The application utilizes **React.js** for the frontend, **Node.js (Express)** for the backend, and **MongoDB Atlas** for the database. The entire project is deployed on **Vercel**.

---

## 🚀 Key Features

### 🎨 Frontend (React.js):
- **Homepage:** Displays product categories.
- **Modern Interface:** Responsive design, user-friendly on all devices.

### 🔧 Backend (Node.js):
- **RESTful API:** Provides product and user data.
- **CRUD Operations:** Manage products.
- **Authentication:** Secured with **JWT**.

### 💾 Database:
- **MongoDB Atlas:** Stores product and user data.

### 🌐 Deployment:
- **Vercel:** Deploys both frontend and backend seamlessly.

---

## 🛠️ Technologies Used

- **Frontend:** React.js, TypeScript, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Deployment:** Vercel

---

### 1️⃣ System Requirements
- **Node.js** >= 14.x
- **npm** or **yarn**
- **MongoDB Atlas Account**
